# EMI Calculator App

A modern EMI Calculator built with React and TypeScript that helps users calculate monthly loan payments, total interest, processing fees, and overall payable amount with interactive visual analytics.

## Features

- Calculate Monthly EMI instantly
- Adjustable down payment slider
- Dynamic loan breakdown
- Doughnut chart visualization using Chart.js
- Processing fee calculation
- Total interest and payable amount calculation
- Responsive and clean UI
- Real-time updates on input changes

## Calculations Included

- Total Loan Amount
- Monthly EMI
- Total Interest Payable
- Processing Fee
- Total Amount Payable

## Interactive Analytics

The app includes a doughnut chart to visually represent:

- Principal Loan Amount
- Total Interest
- Processing Fee

## Tech Stack

- React
- TypeScript
- Chart.js
- react-chartjs-2
- CSS
